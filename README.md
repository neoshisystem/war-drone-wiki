# War Drone Clan Mini-Wiki

GitHub Pages-ready static site for clan **PERSIA**.

Project authority: **Hisystem**

## Change clan/project identity globally
Edit only `assets/js/config.js`:

```js
clanName: "PERSIA",
projectAuthor: "Hisystem",
```

All references update automatically.

## GitHub Pages
Publish the `main` branch from `/ (root)` in Repository Settings → Pages.
